# 阶段一 MVP 路线图

目标：**用本地已有音视频文件，跑通「看懂宠物 → 学习习惯 → 陪伴 → 告诉父母」最小闭环。**

## 范围（做什么）

1. **数据源**：`FileMediaSource` 遍历本地视频/图片/音频，抽帧/切片喂感知层。
2. **感知**：
   - YOLO 检测宠物在不在、位置、是否运动 → 产出事件。
   - 事件触发本地 VLM 对关键帧做一句话语义理解。
   - Whisper 转写人声（可选）。
3. **记忆**：当日事件时间线落地 + 最简作息统计（活跃时段）。
4. **决策**：父母提问 → 组装上下文 → LLM 回答"它今天怎么样"。
5. **父母端 App（RN）**：登录 → 看今日时间线/简报 → 与 agent 文字对话。
6. **实时通道**：打通一条 LiveKit 音视频（父母能看一路画面）。

## 不做什么（留给后续阶段）

- 远程摄像头实时流接入（阶段二）。
- 姿态/行为/情绪细粒度分析、健康预警（阶段三）。
- 多宠物区分、传感器融合（阶段四）。

## 验收标准

- 丢一段宠物视频进去，App 上能看到"几点在干嘛"的时间线和一句话总结。
- 父母问"狗今天乖不乖"，agent 能基于事件给出有依据的回答。
- 父母端能实时看到一路画面并与 agent 对话。
