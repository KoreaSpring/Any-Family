## 一、提示词正文（复制这段给 readdy.ai）

```
帮我设计并生成一个现代、温暖且带科技感的宠物陪伴产品品牌官网，单页长滚动布局，中文为主，面向养宠人群（宠物父母），目标是介绍产品并引导下载 App。

【业务名称】Any-Family（中文名：伴宠）
【一句话定位】全天候宠物陪伴 AI —— 让宠物不孤单，让父母更懂它。
【核心卖点】AI Agent（本地智能大脑）+ 跨平台 App（父母陪伴端）+ 宠物陪伴，三位一体。请在首屏和「工作原理」模块突出这三者如何协同。

【产品本质，务必体现】
- 这不是普通的宠物监控摄像头，而是一个「越用越懂你家宝贝的翻译官 + 健康管家」。
- AI Agent 本体运行在家庭本地服务器上（本地优先 local-first），通过音视频持续感知、陪伴宠物、学习它的作息与习惯；隐私数据不出门。
- 父母通过 iOS / Android App 随时随地了解宠物、与它互动。
- 诚实边界：做的是宠物「情绪/状态/需求的解读」与「健康提示」，不是逐词翻译宠物语言，也不替代兽医诊断。文案避免夸大，用「解读 / 提示 / 置信度」这类措辞。

【视觉风格】
- 整体温暖、治愈、可信赖，同时有科技质感。参考家庭陪伴机器人品牌（如 Always Together 式的温情科技）与温馨宠物生活品牌的调性。
- 主色：温暖的奶橘色 / 焦糖色（#FF8A4C 或 #F5A623 一类）作为品牌强调色，搭配柔和米白背景（#FFF8F2）与深灰蓝文字（#2B2B38）。点缀一个科技感辅色（青蓝 #2DD4BF 或靛蓝）用于「AI/Agent」相关元素。
- 大圆角卡片、柔和阴影、充足留白、圆润无衬线中文字体。配图以真实宠物生活照 + App 界面 + 3D 宠物形象为主。
- 适配移动端，响应式。顶部导航吸顶，含品牌 Logo（一个圆润的爪印 + Any-Family 字样）与「下载 App」主按钮。

【页面结构（从上到下）】
1. 顶部导航：Logo、锚点菜单（产品/功能/工作原理/隐私/下载）、「下载 App」CTA 按钮。
2. 首屏 Hero：左侧大标题「让宠物不孤单，让父母更懂它」+ 副标题点明「本地 AI Agent + 手机 App，全天候陪伴与读懂你的毛孩子」+ 两个按钮（下载 App / 了解原理）；右侧放宠物与手机实时画面结合的主视觉图。背景用柔和暖色渐变。
3. 痛点共鸣区：两句话戳中养宠人焦虑——「不在家时它过得好不好」「它不会说话，我读不懂它」，温柔文案 + 一张真实宠物照。
4. 核心能力区（三位一体）：用三张并排卡片表达 Agent + App + 陪伴：
   - 本地 AI Agent：跑在家里的智能大脑，持续感知、学习、决策，隐私不出门。
   - 跨平台 App：iOS / Android，随时随地看、问、互动。
   - 全天候陪伴：主动互动与守护，不只是被动监控。
5. 三大入口功能区（这是产品门面，重点展示，每个配图 + 标题 + 一句说明）：
   - 🔍 了解宠物：AI 汇总今日概览、时间线、习惯画像，还能对比「品种普遍倾向 vs 你家这只」。
   - 👂 听懂我：把宠物叫声实时解读成「情绪 + 可能需求 + 置信度 + 依据」（结合画面与历史，不是逐词翻译）。
   - 💬 看到我：输入文字，用它熟悉的指令词 + 主人熟悉的声音远程安抚/下指令。
6. 3D 宠物健康形态图亮点区：展示一个可 360° 旋转的 3D 宠物形象，身上像「穴位图」一样高亮可能异常的部位，点击看依据与建议。强调「健康提示，不是诊断，建议就医以兽医为准」。配一张带高亮标注的 3D 宠物示意图。
7. 工作原理区：用四步流程图表达「感知 → 学习记忆 → 解读决策 → 父母端表达」，说明本地服务器与手机 App 如何协同。
8. 隐私与信任区：强调本地优先、数据不出门、生物特征数据可授权可删除；放一个「家庭本地部署」示意。
9. 适用场景区：上班族、经常出差、多宠家庭等，配真实宠物生活照。
10. 下载/行动区：大标题「现在就更懂你的毛孩子」+ App Store / Google Play 按钮 + 二维码占位。
11. 页脚：品牌简介、导航链接、版权、本地优先与「不替代兽医诊断」免责声明。

【文案语气】温暖、真诚、不夸大，像懂宠物的朋友在说话。多用「陪伴、读懂、守护、更懂它」这类词。所有健康相关表述都带「提示 / 建议观察 / 请以兽医为准」。

【交互与动效】滚动时模块轻微淡入上移；卡片 hover 轻微抬起；首屏主视觉可有缓慢浮动动效。保持克制、不花哨。
```

## 三、调优追加指令（按需补发给 readdy）

- 想更科技：「把 Agent 相关模块加入青蓝辅色与轻微发光线条，体现 AI 智能大脑的感觉。」
- 想更治愈：「增加更多真实宠物生活照，减少硬件机器人图，突出家庭温情。」
- 想要暗色版：「再生成一个深色主题版本，背景深灰蓝，品牌橘色作为点睛。」
- 加品牌名变体：「中文名用『伴宠』，英文名用『Any-Family』，Logo 用圆润爪印。」
- 想加数据背书区：「增加一个数据区块：全天候感知、本地隐私、习惯学习、健康提示四个图标 + 一句话。」
